Guide

Navigate the game world by selecting one of the four options inside the game screen. The top, left, right, and bottom options correspond to the rooms surrounding the player character in those directions. Select an available option to move, interact with the room, or use its action; the text on each button describes what will happen. Each successful movement will result in a decrease to your step count. Once you are out of steps, its game over, so try to make it to an exit before you run out!
